How the System Works

The application collects clinical and lifestyle information and sends the data to a Flask-based prediction API.

The trained Logistic Regression model processes the input and returns the predicted MASLD risk as a JSON response.

Disclaimer: This application is an educational machine-learning prototype and is not a medical diagnostic tool.
